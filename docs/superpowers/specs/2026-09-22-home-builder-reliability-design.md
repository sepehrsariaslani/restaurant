# سازنده صفحه اصلی و کامپوننت‌های داینامیک — سند طراحی

## هدف

سازنده صفحه اصلی باید داده‌های واقعی منو را در Builder و Preview نشان دهد، Hero تمام‌صفحه را به‌عنوان یک Variant قابل انتخاب ارائه کند، Preview دسکتاپ و گوشی با رندر عمومی صفحه هم‌خوان باشد، و تمام فیلدهای تصویر از آپلودر استاندارد مدیریت استفاده کنند.

## طراحی

- منبع دسته‌بندی‌ها و محصولات Preview، `getMenuBoot()` است و در `builderBoot` با تنظیمات draft ادغام می‌شود؛ بنابراین داده‌ها هاردکد نمی‌شوند و Preview همان داده‌ای را می‌بیند که صفحه عمومی مصرف می‌کند.
- Hero تمام‌صفحه در رجیستری بلاک و رندر عمومی با Variant `fullscreen` باقی می‌ماند، اما عرض آن full-bleed و ارتفاع آن متناسب با viewport می‌شود. Preview کنترل‌های بصری نیز همین Variant را با کامپوننت عمومی نمایش می‌دهد.
- Preview Builder با همان `RestaurantLandingPage` رندر می‌شود و حالت گوشی از viewport محدود و responsive واقعی استفاده می‌کند؛ لینک‌ها و دکمه‌ها در Preview غیرفعال می‌مانند تا کاربر از محیط مدیریت خارج نشود.
- فیلدهای تصویر بلاک‌ها و محتوای سراسری سایت از `ManagementImageDropzone` استفاده می‌کنند و URL فایل آپلودشده را در draft نگه می‌دارند. ورود دستی URL همچنان ممکن است.
- فرم مزیت‌ها متن‌های فارسی واقعی، آیکن‌های معتبر Design System و ردیف‌های تکرارشونده قابل افزودن/حذف دارد. مقادیر legacy دارای escape یونیکد هنگام نمایش normalize می‌شوند.
- همه تغییرات با توکن‌های موجود، RTL و کامپوننت‌های مدیریت فعلی انجام می‌شود و API بک‌اند جدیدی لازم نیست.

## وضعیت‌های مهم

- وقتی دریافت منو موفق باشد، تعداد گروه‌ها و آیتم‌های Preview از داده واقعی پر می‌شود.
- وقتی دریافت منو شکست بخورد، Builder همچنان قابل استفاده می‌ماند و دسته‌بندی خالی با پیام قابل فهم نمایش داده می‌شود.
- آپلود تصویر حالت در حال آپلود، خطا، پیش‌نمایش، تعویض و حذف دارد.
- داده‌های قدیمی مزیت‌ها بدون شکست رندر می‌شوند و escapeهای `\\uXXXX` به متن فارسی تبدیل می‌شوند.

## معیار پذیرش

1. Variant تمام‌صفحه در palette و Preview دیده می‌شود و در صفحه عمومی تمام‌عرض است.
2. کلید دسکتاپ/گوشی در Builder نتیجه متفاوت و responsive نشان می‌دهد.
3. گروه‌های واقعی منو در Preview و بلوک Categories دیده می‌شوند.
4. هر فیلد تصویر قابل آپلود با File Dropzone است و URL سرور ذخیره می‌شود.
5. فرم مزیت‌ها به‌جای escape خام، برچسب‌های فارسی و آیکن معتبر نشان می‌دهد.
6. تست‌های داده‌ای و build/test فرانت‌اند موفق هستند.
