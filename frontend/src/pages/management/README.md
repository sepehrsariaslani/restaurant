# ساختار صفحات مدیریت رستوران

صفحه‌های مدیریت بر اساس ماژول کسب‌وکار نگهداری می‌شوند. جابه‌جایی این فایل‌ها routeهای عمومی را تغییر نمی‌دهد؛ resolver و importهای `App.vue` مرجع اتصال صفحه به route هستند.

| ماژول | پوشه |
|---|---|
| محصولات، منو، modifier، variant و فرمول/BOM | `catalog/` |
| سفارش، POS، صندوق، تماس و داشبورد فروش | `sales/` |
| مشتری، باشگاه، رزرو و نظرسنجی | `customers/` |
| موجودی، انبار، گردش، تولید، شمارش و هزینهٔ محصول | `inventory/` |
| درخواست مواد و خرید | `purchasing/` |
| پیک، آشپزخانه، میز و شعب | `operations/` |
| حسابداری، کنترل هزینه و گزارش‌ها | `finance/` |
| دسترسی، تنظیمات، چاپ و درگاه | `settings/` |
| سازندهٔ صفحه و قالب‌ها | `builder/` |
| مرجع توکن و کامپوننت‌های دیزاین‌سیستم | `design-system/` |
| داشبورد عمومی مدیریت | `dashboard/` |

کامپوننت‌های تخصصی نیز در `src/components/management/catalog`، `inventory`، `pos`، `tables`، `bi`، `builder`، `notion` و `design-system` قرار دارند. primitiveهای مشترک در ریشهٔ `components/management` می‌مانند.
